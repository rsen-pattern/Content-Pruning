# Reference guides

This folder is intended to hold the **7 source guides** that inform the router
thresholds and the ambiguous-judgment prompt context.

They are **not yet present**. Until they are added here as `*.md`:

- The deterministic router runs unaffected.
- LLM ambiguous-judgment rationale uses a generic best-practice stub
  (`utils/llm.load_guides()`), and the executive-summary timeline citations
  (Doc 3's 4–8 week window, Doc 4's batch-and-monitor rollout) are **unverified
  against the source literature**.

Drop the guides in here (one `.md` per guide) and re-review `methodology.md`
before treating the LLM rationale or thresholds as authoritative.
